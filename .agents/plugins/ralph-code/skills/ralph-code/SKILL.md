# Ralph Code Orchestration Skill

This skill enforces strict adherence to traditional architecture and the 30 anti-vibecoding guidelines:
- Never use Lucide icons, pure white backgrounds, or drop shadows.
- Keep border radiuses strictly between 0px and 3px.
- Use earthy heritage palettes: turmeric gold, terracotta, burlap brown, deep leaf green, and warm cream.
- Ensure all typography uses serif for headings and legible system sans for copy.
